# Phase 1 — decisions taken autonomously

The user asked for phase 1 (hardening plan, then search-protocol plan) to be executed end to end without
check-ins, with every decision that would otherwise have been theirs recorded here with its reason and
what it costs if wrong. Rulings that change a measured number are also in `docs/phase0-execution/sdd-ledger.md`
with a `ledger.log_event`; this file is the complete list, including the ones that do not.

Plans: `docs/superpowers/plans/2026-09-05-phase1-hardening.md`, `docs/superpowers/plans/2026-09-05-phase1-search-protocol.md`.
Execution: subagent-driven, one implementer per task (opus for transcription-grade tasks, fable for integration or
design), one reviewer per task, a whole-branch review at the end of each plan.
